# ทอชีวิตเป็นผืนเสื่อ · A Life Woven

นิทรรศการออนไลน์แบบอินเทอร์แอกทีฟ เล่าพระราชประวัติ **สมเด็จพระนางเจ้ารำไพพรรณี พระบรมราชินี** (พ.ศ. ๒๔๔๗–๒๕๒๗)
ผ่านแนวคิด “ทอชีวิตเป็นผืนเสื่อ” — เส้นยืนคือเวลา เส้นนอนคือสถานที่ โดยใช้ลาย *เสื่อจันทบูร* ที่พระองค์ทรงฟื้นฟู
เป็นทั้งกริดและลวดลายของทั้งเว็บ

An interactive online exhibition on the life of Queen Rambhai Barni, consort of King Prajadhipok (Rama VII).

| ๐๒ | เส้นทางที่ประทับ | แผนภาพหมุด ๖ ที่ประทับ กดดูรายละเอียดได้ |

## คุณสมบัติ

- **สองภาษา** ไทย/อังกฤษ ทั้งเว็บ จำค่าไว้ใน localStorage
- **โหมดสว่าง/มืด** ครบทั้งระบบ
- **มือถือออกแบบใหม่** ไม่ใช่ย่อจากเดสก์ท็อป
- **เข้าถึงได้** — คีย์บอร์ดใช้ได้ทุกส่วน, focus ring ชัด, รองรับ `prefers-reduced-motion`
- ไฟล์เดียวจบ ไม่มี build step ไม่มี dependency

## รันดู

เปิด `index.html` ตรง ๆ ได้เลย หรือเสิร์ฟผ่าน HTTP:

```bash
python3 -m http.server 4488 --directory .
```

แล้วเปิด http://localhost:4488

## หมายเหตุสำคัญ

นิทรรศการนี้จัดทำขึ้น**เพื่อการศึกษาอย่างอิสระ ไม่ใช่เว็บไซต์ของหน่วยงานราชการหรือพิพิธภัณฑ์แห่งใด**

**ภาพประกอบทั้งหมดเป็น SVG ที่วาดขึ้นใหม่เป็นลายเส้นเชิงสัญลักษณ์ ไม่ใช่พระฉายาลักษณ์หรือภาพถ่ายจริง**

ข้อมูลเรียบเรียงจากแหล่งอ้างอิงสาธารณะ วันเวลาบางแห่งอาจต่างกันตามการนับปีปฏิทินเก่า (ปีใหม่ ๑ เมษายน)
